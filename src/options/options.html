Release pages and search work without this. A token is only needed to browse a private collection, and it raises the rate limit from 25 to 60 requests a minute. Create one at discogs.com/settings/developers.

Scrobbling

Used only when a release lists no durations at all. When a release has some, the average of those is used instead. This shifts clock times only — never play counts.

Off means a suite or symphony is scrobbled as a single track.

Off (recommended) uses each artist's canonical name, which matches Last.fm more reliably.

Useful for checking a release before it hits your profile. Last.fm has no delete-scrobble API, so a mistake has to be removed by hand from your library.
